✨ Tentang Club

Apa itu Coders Club?

Coders Club adalah komunitas belajar dan berkarya di bidang teknologi untuk siswa yang tertarik pada coding, web development, problem solving, portofolio, dan kompetisi IT.

🟢

Explorer

Untuk siswa kelas X yang ingin belajar coding lebih awal, walau belum pernah programming sebelumnya.

🔵

Builder

Untuk siswa kelas XI yang ingin memperkuat kembali dasar HTML, CSS, JavaScript, dan latihan project.

🟡

Student Mentor

Untuk siswa kelas XI yang siap membantu junior belajar sekaligus naik level ke materi yang lebih lanjut.

🛠️ Program Belajar

Belajar bukan cuma teori — kita akan build sesuatu

1

Challenge & Logic

Mulai dengan puzzle ringan, computational thinking, dan latihan logika.

2

Mini Lesson

Belajar konsep baru seperti HTML, CSS, JavaScript, DOM, API, atau Git.

3

Build Session

Membangun fitur atau mini project secara langsung.

4

Showcase

Menampilkan hasil, presentasi singkat, dan menerima feedback untuk berkembang.

🌐 Personal Website

Belajar HTML dan CSS sambil membuat halaman profil sendiri.

🗳️ Mini Voting App

Belajar event, array, dan localStorage melalui project voting sederhana.

🎮 Quiz App

Membuat kuis interaktif dengan score system dan tampilan menarik.

📊 Dashboard

Mengenal API dan data display melalui tampilan dashboard sederhana.

🏁 Competition Track

Dua jalur pengembangan

Pilih jalur sesuai minat, bakat, dan tujuan belajarmu.

🧠 Olympiad Track

Cocok untuk siswa yang suka logika, puzzle, algoritma, dan tantangan problem solving.

  • C++ Fundamental
  • Algorithm & Data Structure
  • Past Problem Practice
  • Simulation & Internal Contest
🌐 Product Track

Web Development & Software Project

Cocok untuk siswa yang suka membuat website, aplikasi, UI/UX, dan karya digital yang nyata.

  • HTML, CSS, JavaScript
  • Git & GitHub
  • API, Backend, Database
  • Team Project & Demo Day

❓ FAQ

Pertanyaan yang sering muncul

Apakah harus sudah bisa coding?

Tidak. Coders Club terbuka untuk pemula yang punya minat belajar.

Apakah hanya untuk siswa yang ingin ikut lomba?

Tidak. Kamu bisa ikut untuk belajar, memperkuat dasar, membuat project, atau mempersiapkan kompetisi.

Kapan pelaksanaannya?

Direncanakan setiap pekan pada hari Sabtu atau Minggu, menyesuaikan agenda sekolah.

Apakah boleh menggunakan AI?

Boleh, selama tetap dipakai untuk belajar dan kamu bisa menjelaskan code yang digunakan.
